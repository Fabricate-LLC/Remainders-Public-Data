## Research selection

These guides are editorial selections, not a numerical popularity ranking. The tables below record this run's shortlist, rather than claiming a universal ranked top 20.

Official publisher/store sources take precedence when available. Four movie additions (How to Rob a Bank, A Minecraft Sequel, A Quiet Place Part 3, The Conjuring: First Communion) and the Nintendo Persona 4 Revival date rely on reputable secondary coverage after official destinations were inaccessible or the relevant page could not be found. They are explicitly dated releases in the guides, not release-window estimates. Warner Bros and Amazon MGM destinations returned access errors. The Minecraft guide explicitly reports the announced CinemaCon title; the general release calendar uses the generic sequel label instead. No translations of unannounced localized titles were invented: the new records retain the verified original release names and use translated notes.

## Audit and guardrails

The entire initial 101-record catalog was screened for missing/blank titles, Q-number/database fallbacks, and game/movie category and icon mismatches before additions. No such invalid-title or category records were found. Retained media names were corroborated against the current release guides and official PlayStation/Nintendo listings; Steam's store corroborated titles absent from the console guides (Tenebris Somnia, I Am Your Beast, Back to the Dawn, Cotton Reboot!, Warrior Cats: Clans of the Forest). Nintendo's [Cotton Reboot! High Tension! listing](https://www.nintendo.com/us/store/products/cotton-reboot-high-tension-switch/) corroborates that title.

The updater already rejects empty/whitespace and Q-number labels and assigns Movie/film.fill or Game/gamecontroller.fill to its three media query kinds. The validator already rejects Q-number names in every locale, invalid Game/Movie icons, and all three media icons on Special Event records. No source change was necessary to add those existing guards. There is no existing test suite structure; focused checks were run against temporary invalid catalogs and mocked updater responses without changing production data.

Validation results:

- `python3 scripts/validate_public_events.py`: 108 records validated with Python 3.13.5.
- Whole-catalog semantic audit: no blank/fallback titles, media icon/category mismatches, or stale one-offs.
- Preservation audit: all 89 retained original records unchanged, in original order.
- Validator rejected all 11 invalid catalogs (Q-number and blank titles in each locale; incorrect Game and Movie icons; each media icon on Special Event).
- Updater rejected fallback/blank inputs for all three query kinds and produced the expected media categories/icons for valid input.
- `git diff --check` passed.
